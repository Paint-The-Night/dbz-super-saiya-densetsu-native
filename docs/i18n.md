# Native i18n plan (Super Saiya Densetsu)

## Policy

- **No runtime ROM patching.** English and Japanese both boot the same clean
  Japanese Rev 1 image (SHA-256 gate unchanged).
- Language is chosen on the in-game **LANGUAGE / 言語** boot menu
  (`src/web_main.c`), which calls `dbz_i18n_set` before the emulator starts.
- Dialogue EN uses the **text API** (`docs/text-api.md`): C tables + pointer-swap
  WRAM overlay — never IPS/BPS at runtime.
- Klepto Software English IPS may be used as **reference wording only** under
  `research/klepto-reference/`. Never apply it in the product path.
- Tooling: `tools/extract_script_strings.py` dumps JP pointers/strings and can
  align Klepto EN bytes offline (`--klepto`); `--c-inc` / `--c-inc-banks`
  regenerate `text_en_scripts.inc` (main) and `text_en_banks.inc` (menu/battle).

## Honest EN ship state

1. Menu remains.
2. Selecting **ENGLISH** → `dbz_i18n_set(DBZ_LANG_EN)` → boot **clean** ROM.
3. Status may briefly show: `English: native translation layer in progress`.
4. **Pointer-swap landed** for every far-table sel with C tables: main
   **366 / 366** (`text_en_scripts.inc`) plus menu/battle **569**
   (`text_en_banks.inc`). Streams walk EN glyph indices via WRAM overlay.
   23–42 alias dest 43 (unused in JP and Klepto). Idx 365 is a 90-byte
   7F-not-FE walk — the old 2745-byte “oversize” was leftover JP after
   Klepto packed the last dest to `06:C64F`. Overlay stays `$7E:E000`/`$0800`.
5. **EN font upload landed**: `dbz_text_en_font_ensure` on `00:90C1` installs
   Klepto-ref 2bpp tiles at VRAM `$2000` (same dest as JP DMA) for dialogue.
6. **Opening crawl EN**: the title crawl never hits CF3A (`$0733` stays 0).
   `dbz_text_en_intro_ensure` installs Klepto-ref CHR + BG1/BG2 nametables from
   `text_en_intro.inc` on **leave-vblank** (hook on `snes->leaveVblankHook`)
   while BG3 is `$7000`/`$4000`. Title EN≠JA from frame **1273**; crawl still
   differs ~2093 (`en_title_smoke` / `en_intro_smoke`).
7. **Overworld menu chrome EN**: bank `$02` Klepto-ref bytes via
   `cartRomFilter` (`text_en_chrome.inc`). Font ensure re-applies on
   every `00:90C1` so overworld dialogue stays Latin.
8. **Title EN**: AE6A small-font legend/copyright via cart filter;
   `dbz_text_en_title_ensure` blanks BG0 kanji tm (`$1464`) and hides the pink
   ドラゴンボールゼット circle OBJ (`Y=$F0`). Klepto has no large-font EN
   subtitle bitmap (`$10`/FCF0/FD30 stubs are font/intro paths, not a title
   subtitle); stubs stay out.
9. Only 7 unused sel-7 slots (trailing `93AE` aliases of sel 0 string 0) keep
   JP ROM bytes. Same unused dests in JA.

## Text pipeline (evidence)

### Not dialogue

| PC / range | Notes |
|------------|-------|
| **05:DEC3–DF5F** | Actor **script walker** opcodes `00/03/01/22` on `[$00]` via `$002C/$0030,Y`. Native: `actor_script_dec3_step`. **Not** the dialogue print leaf. |
| **05:CAFA** jump table | Actor/face/slot ops; adjacent to stream setup, not glyph text. |
| **00:8732** | Generic CPU→VRAM word copy (many consumers). |

### Dialogue decoder (bank `$01`)

| PC / RAM | Notes | Source |
|----------|-------|--------|
| **01:CF3A–CFA0** | Resolve message: `$0733` ×3 indexes far table **`07:8F16`**; `$0723` ASL indexes u16 pointer table; result → DP+`$00` long; cursor → DP+`$20`, Y←`$071D`. **Native:** `text_script_cf3a_step` + EN pointer-swap. | ROM + native |
| **07:8F16** | 24-bit bank table; **index 2 = `06:8000`** (main); 0=`07:8F2E`, 1=`07:8F82`, 3=`07:9226`, 4–7 short sets. Bank-07 ptr tables packed through `07:93AE`. | ROM `$38F16` |
| **06:8000 / file `$30000`** | **366** u16 LE string pointers; strings from **`06:82DC`**. Last JP line ends ~`$35108`; Klepto last dest is `06:C64F` (90 B walk). | ROM + RHDN notes |
| **01:CFB2–CFC3** | Fetch loop head: `LDX $20` / **`LDA [$00],Y`** / `STA $04` / `INY` / `CMP #$01` → gap via `JSL $01D00B`, else fall to opcode dispatch at `$CFC4`. **Native:** `text_script_cfb2_step` + `dbz_i18n_filter_script_byte`. | ROM + native |
| **01:CFC4+** | Control dispatch: `FF`/`FE`/`FD`/`FC`/`F6+`/`F4`→`$D293`; `$A0–$DF` via `JSL $01BC88`; glyph emit `STA $7E3000,X`. | ROM |
| **01:D000 / D00B** | Write glyph tile pair to **`$7E3000,X`** (attr `#$24`); `D00B` shared INC `$071D`/`$071F` / RTL (also space gap). Native covers `D00B–D012`. | ROM + native |
| **`$7E3000,X`** | Dialogue **glyph word buffer** (also reused by map pattern fills elsewhere). | ROM + ram-map |
| **`$071D` / `$071F` / `$0721`** | Text cursor / position counters around CF80–CFA0. | ROM |
| **`$0723` / `$0733`** | String index / far-table bank selector. | ROM |
| **`$7E:E000`** | Host EN script overlay (text API); JA never touches. | text-api |

### Stream encoding (main script)

- Custom 1-byte glyph indices (not ASCII / Shift-JIS).
- **`F4 <face> 7E`** — open box / speaker.
- **`FF`** line, **`FE`** page, **`7F`** end box, **`01`** gap (CFB9 path).
- High bytes (`$A0+`, `$C8–$CC`, `$E0+`) take multi-byte / table expand paths.
- Klepto EN keeps the same control framing but retargets glyph indices and
  inserts font data into formerly empty **bank `$91`** (file `$088000`, JP=`FF`).

### Font / VRAM

| Item | Notes |
|------|-------|
| JP font leaf | **`00:90C1`**: decompress `$08:8000` → `$7E9000` → DMA VRAM **`$2000`**. |
| Klepto EN font | 2bpp `$1800` @ `$91:8036` (file `$088036`) — **reference extract** in `src/text_en_font.inc`. |
| Native EN | `dbz_text_en_font_ensure` on `90C1` RTL writes the same VRAM dest; JA no-op. |
| Tilemap | Glyph indices → `$7E3000,X` with attr `#$24` (unchanged). |
